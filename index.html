Compiled Intent: Enforcing Architectural Invariants for LLM Coding Agents

Vijay Anant

Wikis don't compile. Design intent—the non-negotiable boundaries, trade-offs, and invariants recorded in ADRs and RFCs—usually remains inert documentation that neither compilers nor AI agents can enforce.

When teams try to fix this by stuffing entire specifications into the prompt, they trigger The Ammunition Effect: rather than upholding rules, the model seizes on peripheral background narratives, historical trade-offs, and examples to rationalize approving forbidden shortcuts.

We introduce Compiled Intent (intent), an architectural coprocessor that compiles design specifications into an offline vector and AST database. By isolating and retrieving only compact, normative constraint chunks (~750 tokens), the engine strips away this rationalization ammunition—slashing context payloads by 94.6% and raising adversarial enforcement accuracy by 12.8% to 17.9% across local models (qwen2.5-coder:14b and gemma3:12b).

Systems & Protocols

Compiled Intent (intent)

Rust Engine

A headless architectural coprocessor and Model Context Protocol (MCP) server that compiles human design intent into synchronized Apache Arrow and LanceDB indices.

  • Shift-Left Synthesis: Proactively supplies exact constraint chunks into IDE agents via standard I/O MCP.
  • Shift-Right Auditing: Intercepts raw code diffs at pre-commit and CI/CD gates to block architectural regressions.
  • Zero Cloud Leakage: Runs embedded vector and full-text Tantivy retrieval locally with zero external telemetry.
