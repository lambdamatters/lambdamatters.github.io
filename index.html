Newton Reborn: Discovering the Inverse-Square Law with Generative AI

Raghu Ugare · Lead Researcher

Black-box neural networks fit training curves, not physical laws.

While a standard multilayer perceptron reaches R² = 0.940 in-distribution, its accuracy collapses under extrapolation (R² = 0.626 at 1000× range). By coupling an information-theoretic VAE bottleneck (β = 0.4) with symbolic regression via risk-seeking policy gradients, this pipeline rediscovers Newton's exact inverse-square law from 20,000 noisy observations without prior functional assumptions, retaining R² = 0.998 across 1000× extrapolation.

Report 02 · September 2026 · ⇄ Systems × ∂ AI

Compiled Intent: Enforcing Architectural Invariants for LLM Coding Agents

Vijay Anant · Lead Architect

Wikis don't compile. Prompt stuffing invites the Ammunition Effect.

When teams dump entire specification documents into an agent's prompt, models use background prose and historical trade-offs to rationalize taking forbidden architectural shortcuts. The Compitent engine indexes architecture specifications into normalized vector and AST databases, retrieving only concise, normative constraint chunks (~820 tokens). Context payload drops by 94.7% while adversarial rule enforcement improves by 12.8% to 17.9%.

Σ Cryptography × ⇄ Systems

Akshara

A foundational architecture for high-secrecy, local-first applications built on security through architecture rather than policy. By combining client-side encryption, content-addressed permanence (CIDs), and causal Merkle-DAG synchronization, Akshara makes hosting infrastructure completely blind, swappable, and irrelevant to data secrecy.

  • Content-Addressed Merkle-DAGs: Immutable DAG-CBOR state graphs with causal reconciliation independent of wall-clock time.
  • Hierarchical Deterministic Identity: Master seed derivation providing functional branch isolation and key revocation walking.
  • Zero-Knowledge Relays: Content-blind synchronization using XChaCha20-Poly1305 authenticated encryption with forward secrecy.

⇄ Systems × λ Functional

Compitent

A headless architectural coprocessor and Model Context Protocol (MCP) server that compiles human design intent into synchronized Apache Arrow and LanceDB vector indices.

  • IDE Integration: Serves targeted constraint chunks to editor agents via the Model Context Protocol (MCP stdio).
  • Pre-commit & CI Gates: Intercepts unified diffs in git hooks and pipelines to detect boundary violations before merge.
  • Local & Offline Execution: Operates entirely on-device using LanceDB and Tantivy with zero telemetry or remote calls.

Σ Mathematics × ⇄ Systems

AutoCombo

Designed jointly by Raghu Ugare and Vijay Anant. An algorithm mapping product catalogs to prime numbers, collapsing combo selection and multiset containment into single integer divisibility operations.

  • Prime Factorization Mapping: Assigns unique primes to products, turning shopping carts and combo bundles into unique composite numbers.
  • Constant-Time Containment Check: Sub-multiset matching reduces to single modulo division (S ≡ 0 mod C).
  • Total Function Safety: Enforces mathematical determinism without combinatorial search trees.
